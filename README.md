# RUBY & RUBY ON RAILS

> Um repositório aberto para quem quer **aprender Ruby e Ruby on Rails** do zero, em português, no seu próprio ritmo.

## Por que este repositório existe

Aprender a programar fica mais fácil quando o material é claro, está organizado e foi escrito na nossa língua. Este repositório nasceu com um objetivo simples: **incentivar o aprendizado**. Ele reúne num só lugar um caminho de estudo que vai dos primeiros passos em Ruby até uma aplicação web completa com Rails.

A ideia não é só entregar conteúdo pronto. É ajudar você a **criar o hábito de estudar**, praticar com as próprias mãos e ganhar confiança para seguir sozinho. Errar, testar no `irb`, quebrar o código e consertar de novo fazem parte do processo.

Este material foi pensado para:

- **Quem está começando** a programar e quer uma linguagem amigável. O Ruby foi criado para deixar o programador feliz.
- **Quem já programa em JavaScript** e quer migrar ou ampliar o repertório para Ruby.
- **Professores e monitores** que procuram um material de apoio para aulas e grupos de estudo.
- **Qualquer pessoa curiosa** que queira entender como funciona o desenvolvimento web com Rails.

## Como estudar com este material

1. **Siga a ordem.** Cada documento parte do que foi visto no anterior.
2. **Digite os exemplos.** Evite copiar e colar: escrever o código você mesmo ajuda a fixar.
3. **Experimente.** Mude os valores, provoque erros e veja o que acontece no `irb` ou no `rails console`.
4. **Faça os exercícios** antes de avançar. Eles mostram o que você realmente entendeu.
5. **Construa algo seu.** Ao terminar o projeto prático de Rails, invente uma variação: uma lista de compras, um diário, um catálogo de livros.
6. **Estude com outras pessoas.** Explicar um conceito para alguém é uma das melhores formas de aprender.

## Pré-requisitos

- Vontade de aprender. É o único requisito obrigatório.
- Um computador com **Ruby 3.x** instalado (veja [Instalação e ambiente](docs/ruby/02-instalacao-e-ambiente.md)).
- Para a trilha de Rails, **Rails 7.1+** (os exemplos também funcionam no Rails 8 com pequenas diferenças, indicadas no texto).
- Um editor de código de sua preferência (VS Code, RubyMine, Vim...).

## Contribua

Este é um projeto de aprendizado coletivo, e toda ajuda é bem-vinda:

- Encontrou um erro de digitação, um exemplo que não funciona ou uma explicação confusa? **Abra uma issue.**
- Quer adicionar um exercício, um exemplo melhor ou um tema novo? **Envie um pull request.**
- Usou o material numa aula ou grupo de estudo? Conte como foi, porque isso ajuda a melhorar o conteúdo para os próximos.

Ao contribuir, mantenha o tom didático, escreva em português e siga o formato dos documentos existentes (explicação, exemplos, resumo e exercícios).

## Uma última palavra

Ninguém aprende a programar de uma vez. Aprende-se um pouco por dia. Se algo não fizer sentido agora, volte depois, releia, teste de novo. Cada exercício resolvido é um passo a mais.

**Bons estudos, e divirta-se programando em Ruby!** 💎
